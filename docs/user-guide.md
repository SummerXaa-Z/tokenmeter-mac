# 用户指南

## 安装与打开

从 [GitHub Releases](https://github.com/SummerXaa-Z/tokenmeter-mac/releases) 下载适用版本，按该版本说明安装到 `/Applications`。签名和公证状态以实际下载的产物及系统检查为准；源码构建成功不能说明发行包已公证。

首次打开遇到系统拦截时，先核对下载来源、版本和签名说明，再按 macOS 提供的「隐私与安全性」提示处理。不要通过自动清除 quarantine 或提权绕过安装检查。

应用运行在菜单栏。点击图标打开总览，进入来源页查看详情；设置页可以控制监控来源、刷新、菜单栏显示、通知、订阅月费和开机自启。

## 配置来源

Claude Code、Codex、Kimi Code、OpenCode、Gemini CLI、GitHub Copilot CLI 与 Qwen Code 的用量来自本机记录。检测到可用路径后可以采集，对应来源在当前范围有用量时出现在首页；记录路径、指标与限制见 [来源覆盖](local-source-coverage.md)。

Cursor 通过本机 Cursor 登录态查询账户 Dashboard，不是纯离线扫描。Codex 实时额度默认关闭，显式启用后才读取本机认证并查询账户；本地会话中的额度快照与远程最新额度可能不同。

Kimi 额度可用手填 Coding Key 查询官方接口；未手填时支持本机已运行的 CLI 服务。智谱 / GLM 额度需要在设置中启用并选择对应官方域名。方舟额度通过本机 `arkcli` 查询，受已安装工具和登录状态影响。

DeepSeek API Key 用于查询余额，用量统计需要单独的平台登录 Token。在设置中选择「网页登录自动同步」并完成官方平台登录，应用验证可用后保存；自动同步失败可按设置页提示手动配置用量 Token，过期后需重新同步。

远程查询会发送对应凭据到服务端。API Key、登录 Token、Cookie 与诊断中的个人信息都不要粘贴到公开 issue 或截图。

## 统计口径

总览提供 1D、7D、30D 和全部范围，来源开关决定参与汇总的来源。更长范围依赖本机已留存或回填的记录；缺失历史不会自动变成完整平台账单。

模型榜的排序、数值、占比和条形图使用同一选定指标。Skills 的来源筛选同时影响榜单、趋势、详情与导出；同名模型在不同来源下仍保留来源信息。

API 等价费用按内置模型价格快照估算，以美元为参考；未收录模型显示缺价与覆盖范围，不能把缺价解释为免费。订阅费用与回本比较也依赖手填月费和已计价用量，不能代替实际扣费。

热力图可按日、周、月查看，并切换跨度或翻页。强度由当前范围内用量决定，历史不足时只显示已留存记录；趋势、环比和缓存统计遵循各来源原始指标，缺失的缓存字段不作猜测。

## 导出

「设置 → 用量导出」支持全部、近 30 天、近 90 天和自定义起止日期。近 N 天包含今天，自定义按自然日包含两端；CSV 的汇总、价格覆盖和订阅比较随所选范围计算，订阅周明细使用其单独的完整周口径。

各图表、模型榜、Skills 和详情页也提供对应 CSV。保存成功以实际文件与页面反馈为准；导出包含来源、模型等统计信息，分享前检查内容。

## 数据存储

| 数据 | 位置与用途 |
| --- | --- |
| 手填 API Key 与平台用量 Token | macOS Keychain |
| 来源开关、刷新、通知、订阅等偏好 | UserDefaults，沿用 Bundle ID `com.deepseek.monitor.mac` |
| 按天汇总 | `~/Library/Application Support/TokenMeter/history.json` |
| 按天模型明细 | `~/Library/Application Support/TokenMeter/model-history/YYYY-MM.json`，按月分片 |
| 原始 CLI 记录 | 各工具自己的目录；TokenMeter 只读用于统计，不上传原始会话 |

统计历史是本机聚合记录，不是原始会话备份。历史 Tauri 版本的 `DeepSeekMonitorMac/config.json` 不再作为原生版本配置；迁移或清理旧文件前自行确认其用途并保留需要的数据。

## 排查

先检查「设置 → 工具与维护」的数据源健康一览，查看路径存在性、最后写入时间和最近一次采集结果。路径存在不等于当前范围有用量，读取失败也不等于零用量；失败后可能继续展示上次成功快照。

需要反馈时导出脱敏诊断，检查内容后附上应用版本、macOS 版本、来源、复现步骤和预期结果。诊断不应包含凭据或会话内容，公开分享前仍需检查；安全问题按 [SECURITY.md](../SECURITY.md) 处理。

首次安装、实时额度、通知和真实更新的结果受系统权限、账户、工具格式与发布签名影响。隔离示例窗口展示的状态不能作为这些行为的验收结果。
